# コーディングルール詳細

> CLAUDE.md の「絶対ルール」の補足。

---

## 1. コード構造と品質ルール

### 📏 サイズ制限
- 1関数 50行以内、1クラス 500行以内を目安に分割

### 📂 配置ルール
- 独自コードは `app/Customize/` 配下に置く。`src/Eccube/` は編集しない
- 本体の挙動変更は Entity Trait / FormExtension / EventSubscriber / テンプレート上書きで行う

## 2. 型定義ルール

### 🚫 禁止事項
- 型宣言なしの引数・戻り値
- 静的解析エラーの握りつぶし

### ✅ 推奨事項
- `declare(strict_types=1);`
- 依存はコンストラクタインジェクションで受け取る

## 3. 許可リスト方式（ポジティブリスト）
「何でないか」を列挙するネガティブリストは新しい値が追加されたときに壊れる。「何であるか」を列挙するポジティブリストを使い、未知の値は安全側に倒す。

## 4. 表示ロジックと計算ロジックの同期
金額・送料・税計算などを表示側と計算側で別々に実装しない。変更時は両方を同時に確認する。
